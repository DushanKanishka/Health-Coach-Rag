# Knowledge Base Source PDFs

These PDFs are the raw sources for the RAG knowledge base (extracted into
`kb/interim/*.txt` and embedded into `kb/processed/*.parquet`). They are not
committed to version control (see `.gitignore`) — download them from the
links below if you need to rebuild the knowledge base from scratch.

| File | Source |
|---|---|
| `who_physical_activity.pdf` | [WHO Guidelines on Physical Activity and Sedentary Behaviour](https://www.who.int/publications/i/item/9789240015128) |
| `Physical_Activity_Guidelines_2nd_edition.pdf` | [Physical Activity Guidelines for Americans, 2nd edition (health.gov / ODPHP)](https://odphp.health.gov/sites/default/files/2019-09/Physical_Activity_Guidelines_2nd_edition.pdf) |
| `who_healthy_diet.pdf` | [WHO Healthy Diet Fact Sheet](https://www.who.int/news-room/fact-sheets/detail/healthy-diet) |
| `eatwell_guide.pdf` | [Eatwell Guide (GOV.UK / Public Health England)](https://www.gov.uk/government/publications/the-eatwell-guide) |
